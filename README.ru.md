# Veya Music

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | **Русский** | [Português (Brasil)](README.pt-BR.md)

Veya Music — многоплатформенный музыкальный плеер для Windows и Android с рекомендациями, которые строятся по вашей собственной истории прослушивания. Он ищет и показывает музыку Kuwo, Kugou, QQ Music, NetEase Cloud Music и Migu в одном месте, а воспроизводит треки через пользовательские скрипты источников, совместимые с LX Music. Небольшой собственный сервер Veya Sync синхронизирует компьютер и телефон и позволяет передавать воспроизведение с одного устройства на другое.

> Интерфейс приложения пока доступен только на китайском языке.

## Возможности

- **Один поиск по пяти платформам**: треки, плейлисты, площадка плейлистов и чарты Kuwo, Kugou, QQ Music, NetEase Cloud Music и Migu, тексты песен с переводом.
- **Скрипты источников**: импортируйте пользовательские скрипты источников LX Music (`.js`) и включайте несколько сразу. Тест скорости в один клик ранжирует их, при воспроизведении предпочитаются быстрые и надёжные, а если все не сработали, тот же трек ищется на другой платформе.
- **Защита от не того трека**: если скрипт вернул аудио, длительность которого не совпадает с треком (другая песня или 30-секундный фрагмент), автоматически пробуется следующий скрипт.
- **Рекомендации без аккаунта**, целиком по локальной истории:
  - Подборка дня: 30 треков в день, у каждого указана причина; треки с отметкой «не интересно» больше не появляются, а похожие треки и этот исполнитель опускаются ниже.
  - Радио похожих треков: начинается с любого трека и играет без остановки.
  - Автопродолжение: когда список заканчивается в последовательном режиме, дальше идут похожие треки.
  - Страница «Обзор»: треки, которые могут понравиться, рекомендуемые плейлисты, чарты и популярные плейлисты.
- **Где сейчас играющий трек**: текущий трек подсвечен, кнопка «сейчас играет» прокручивает к нему, а панель плеера показывает, из какого списка он запущен.
- **Ваши плейлисты**: сохраняйте онлайн-плейлисты и обновляйте их позже; сортируйте плейлист по числу ваших прослушиваний, недавно прослушанным, названию, исполнителю или длительности, либо показывайте только прослушанные или ещё не прослушанные треки. Площадку плейлистов и поиск плейлистов можно сортировать и фильтровать по прослушиваниям и избранному.
- **Импорт плейлистов** по ссылке «поделиться» из NetEase Cloud Music, QQ Music, Kugou, Kuwo, Migu или Soda Music (Qishui); для других приложений вставьте строки «название - исполнитель», и каждый трек будет сопоставлен. «Мои списки» из LX Music переносятся в один клик.
- **Текст на рабочем столе** с пословной подсветкой, настраиваемой прозрачностью текста и подложкой; **загрузки** (с `.lrc`, можно слушать офлайн); **таймер сна**; светлая и тёмная темы; значок в трее; мультимедийные клавиши.
- **Прокси**: как в системе, всё напрямую или фиксированный порт прокси.
- **Синхронизация и передача между устройствами** через ваш собственный сервер [Veya Sync](#veya-sync-собственный-сервер-синхронизации): плейлисты, история и рекомендации, скрипты источников и часть настроек; продолжите текущий трек на другом устройстве, отправьте трек на другое устройство или слушайте вместе синхронно.

## Приложение для Android

Тот же интерфейс и те же функции, что и в версии для компьютера, плюс: фоновое воспроизведение; управление с экрана блокировки, из уведомления и с гарнитуры (в уведомлении есть кнопки «нравится» и текста песни); **плавающий текст** поверх других приложений; текущая строка текста на экране блокировки и на дисплее автомобиля по Bluetooth; загрузки в папку телефона `Music/Veya Music`; привязка к серверу синхронизации по QR-коду; обновления внутри приложения.

## Начало работы

В Veya Music нет ни аудио, ни скриптов источников. Чтобы слушать музыку:

1. Возьмите один или несколько пользовательских скриптов источников LX Music (`.js`). В папке [`sources/`](sources/) лежат сторонние скрипты, собранные из открытых источников и проверенные; результаты — в [sources/README.md](sources/README.md) (на китайском).
2. В приложении откройте **Настройки → Управление источниками** и импортируйте файлы скриптов (версия для компьютера может импортировать целую папку).
3. Нажмите **Тест скорости**. После этого воспроизведение предпочитает самые быстрые рабочие скрипты, а неработающие можно отключить одним щелчком.

## Veya Sync (собственный сервер синхронизации)

Синхронизация, передача воспроизведения, отправка треков и совместное прослушивание работают через Veya Sync — одну небольшую программу (около 7 МБ, около 10 МБ памяти), которая запускается на вашем собственном Linux-сервере (x86_64 или ARM). Данные остаются на вашем сервере.

**Установка** (запускать от root):

```bash
curl -fsSL https://github.com/aileboeth/Veya-Music/releases/latest/download/veya-sync-install.sh | bash
```

Если сервер не может достучаться до GitHub (например, в материковом Китае), используйте зеркало:

```bash
curl -fsSL https://p.jackyu.cn/https://github.com/aileboeth/Veya-Music/releases/latest/download/veya-sync-install.sh | bash
```

В конце появятся QR-код и код привязки, начинающийся с `veya1.`. На компьютере вставьте код в **Настройки → Синхронизация и устройства**; на телефоне отсканируйте QR-код в **Моё → Синхронизация устройств**. На облачном сервере также откройте **TCP 7650** в группе безопасности провайдера.

**Другие команды**: `veya-sync info` снова показывает код привязки, `veya-sync update` обновляет (данные и код сохраняются), `veya-sync reset-key` меняет ключ.

**Удалить всё** (программу, службу, автозапуск, команду `veya-sync`, добавленные правила брандмауэра, системного пользователя `veya-sync` и все данные):

```bash
veya-sync uninstall --purge --yes
```

Без `--purge` удаляется только программа, а данные остаются в `/opt/veya-sync` для повторной установки. Если команды `veya-sync` уже нет:

```bash
curl -fsSL https://github.com/aileboeth/Veya-Music/releases/latest/download/veya-sync-install.sh | bash -s -- uninstall --purge --yes
```

Работа за Nginx / 1Panel с собственным доменом, установка без root и другие параметры описаны в [docs/SYNC.md](docs/SYNC.md) (на китайском).

## Сборка из исходного кода

Компьютер (Node.js и npm):

```powershell
npm install
node node_modules\electron\install.js   # npm 12 пропускает скрипты установки, поэтому Electron скачивается вручную
npm run dev        # режим разработки
npm run build      # сборка в out/
npm run dist       # установщик в dist/
```

Android (JDK 17+ и Android SDK, путь к SDK — в `android/local.properties`):

```powershell
npm run build:android                      # упаковать интерфейс в android/app/src/main/assets/www
cd android; .\gradlew.bat :app:assembleDebug
```

Сервер синхронизации (Go): `cd server; go test ./...`, а `server/build.ps1` собирает двоичные файлы для Linux.

Автоматические проверки используют отдельную папку данных `.e2e/` и не трогают ваши настоящие данные:

```powershell
npm run build
powershell -File tools\run-e2e.ps1 -Steps tools\e2e\features.cjs -Fresh
powershell -File tools\e2e\sync-run.ps1   # запускает локальный Veya Sync и синхронизирует две папки данных
node tools\test-sync-util.mjs; node tools\test-android-shims.mjs
```

**Выпуск версии**: увеличьте `version` в `package.json` (общая для компьютера, Android и сервера) и добавьте запись в начало `src/renderer/src/changelog.json`; запустите `powershell -File tools\release.ps1`, который складывает всё в `dist\release-<версия>\`; создайте релиз на GitHub с тегом `v<версия>`, вставьте `release-notes.md` в описание и загрузите остальные файлы.

## Структура проекта

- `src/main`: главный процесс Electron (выполнение скриптов источников, онлайн-данные, выбор источника и тест скорости, прокси, обновления, движок рекомендаций, загрузки, импорт из LX Music, импорт плейлистов)
- `src/main/lx`: musicSdk из lx-music-desktop (Apache-2.0, см. `NOTICE`)
- `src/main/sync`: движок синхронизации; `src/renderer/src/remote.ts`: передача воспроизведения, отправка треков, совместное прослушивание
- `src/preload`: preload-скрипты (`userApi.js` — изолированная среда выполнения для скриптов источников)
- `src/renderer`: интерфейс (Vue 3), общий для компьютера и Android; `MobileApp.vue` — оболочка для телефона
- `src/android`: «главный процесс» Android, который переиспользует `src/main` внутри WebView (`shims/` заменяют API Node / Electron; скрипты источников работают в Web Worker)
- `android/`: нативная часть Android (Kotlin): хост WebView, фоновое воспроизведение через ExoPlayer, плавающий текст, загрузки, сеть
- `server/`: сервер Veya Sync (Go) и скрипт установки в одну строку
- `sources/`: сторонние скрипты источников, собранные из открытых источников
